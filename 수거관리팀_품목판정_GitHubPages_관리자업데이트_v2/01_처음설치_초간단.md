# 품목판정 사이트 - 처음 설치 (GitHub Pages)

## 준비물
- GitHub 계정 1개
- 이 압축파일을 푼 폴더

> **중요**: GitHub Pages 무료 공개 방식은 사이트 주소를 아는 사람이 접근할 수 있습니다. `robots.txt`와 `noindex`는 검색엔진 노출을 줄이는 용도일 뿐, 로그인 보안은 아닙니다.

## 1. GitHub 저장소 만들기
1. https://github.com 접속 → 로그인
2. 오른쪽 위 `+` → **New repository**
3. Repository name: `item-archive`
4. **Public** 선택
5. `Create repository` 클릭

## 2. 사이트 파일 올리기
1. 저장소 화면에서 **Add file → Upload files**
2. 압축을 푼 `수거관리팀_품목판정_GitHubPages_관리자업데이트` 폴더 안으로 들어갑니다.
3. `index.html`, `assets`, `data`, `images`, `docs`, `robots.txt` 등을 **전부 선택해서** 업로드합니다.
   - ZIP 파일 자체를 올리는 것이 아닙니다.
4. 아래 **Commit changes** 클릭

## 3. GitHub Pages 켜기
1. 저장소 상단 **Settings**
2. 왼쪽 **Pages**
3. `Build and deployment` → Source를 **Deploy from a branch**
4. Branch: `main`
5. Folder: `/(root)`
6. **Save**
7. 1~3분 기다린 뒤 화면에 표시되는 사이트 주소를 엽니다.

주소 예시:
`https://내깃허브아이디.github.io/item-archive/`

## 4. 사이트에서 수정/추가하기
1. 사이트 오른쪽 위 **관리자 편집** 클릭
2. 신규 사례 등록 또는 기존 사례의 **수정** 클릭
3. 내용을 고치고 **임시 저장**
4. 수정 내용은 그 PC의 브라우저에만 보입니다.
5. 모든 수정이 끝나면 **게시용 data.json 받기** 클릭
6. `items.json` 파일이 다운로드됩니다.
