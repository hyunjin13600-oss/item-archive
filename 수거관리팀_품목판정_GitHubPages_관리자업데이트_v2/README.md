# 수거관리팀 품목판정 아카이브 - GitHub Pages 관리자 업데이트 방식

- 빠른 정적 검색/사진 조회
- 사례 비교
- 관리자 편집 모드
- 신규 사례/수정/삭제를 브라우저 localStorage에 임시 저장
- `게시용 data.json 받기`로 전체 게시용 자료 생성
- GitHub의 `data/items.json`만 교체하면 전체 사용자에게 반영
- 기존 사례 사진은 `images/` 폴더 사용
- 신규 등록 사진은 자동 축소 후 `items.json` 안에 포함

처음 설치: `01_처음설치_초간단.md`
수정 후 게시: `02_수정후_전체공유_방법.md`
